# YoYoLetrasAI 3.6.0 — publicación segura

Este árbol conserva el backend y la configuración funcional 3.6.0 del paquete de entrega. Debido a restricciones del canal automatizado para transportar archivos grandes y ciertos contenidos sensibles, el shell visual se mantiene reducido y el módulo de credenciales usa únicamente secretos de servidor/Vercel OIDC. No se incluyen secretos en el repositorio.
