# Módulo de estudiantes

Este módulo administra fichas básicas y matrículas institucionales.

- Los datos se filtran por organización mediante RLS.
- Docentes y equipos autorizados pueden consultar y crear fichas.
- Los perfiles PIE/DUA se almacenan por separado y solo son visibles para roles PIE, UTP, dirección y administración autorizada.
- No se almacenan diagnósticos en la tabla general de estudiantes.
- Las evidencias pedagógicas y relaciones familiares se incorporarán en migraciones posteriores.
