## Arquitectura de publicación

El repositorio de GitHub es la fuente oficial del código. La aplicación se publica en Vercel y utiliza Supabase para base de datos, autenticación y servicios backend.

Las futuras actualizaciones deben realizarse en la rama `main` del repositorio oficial y publicarse en el dominio permanente indicado anteriormente.

## Seguridad

Las claves privadas y `SUPABASE_SERVICE_ROLE_KEY` nunca deben almacenarse en GitHub. Deben mantenerse únicamente como variables de entorno cifradas en Vercel. El frontend debe utilizar exclusivamente la URL pública y la clave publicable de Supabase.

Este repositorio contiene la base consolidada del frontend, arquitectura, documentación, sistema de diseño, migraciones y flujos iniciales de la plataforma.
